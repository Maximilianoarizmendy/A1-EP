### 🔹 Slide 4: Interesting Facts (Versión Profundizada)

* **Lo que muestra la pantalla:**  
  `01. Ada Lovelace • First computer programmer in history (19th century)`  
  `02. Global Scale • Millions of developers use JavaScript & Python daily`  
  `03. Modern Era • Web applications and AI integration are transforming tech`

* **Lo que debes decir (Speech Completo y Profundizado):**
  > *"Now, let me share three fascinating facts about technology:*  
  >  
  > *First: Ada Lovelace was the first computer programmer in history. In the nineteenth century, she wrote the first algorithm for an early mechanical calculator, long before electronic computers were invented.*  
  >  
  > *Second: On a global scale, millions of developers code in JavaScript and Python every day. JavaScript powers interactive websites in our browsers, while Python is the number one language for Data Science and Artificial Intelligence.*  
  >  
  > *And third: In this modern era, web applications and AI are transforming the world. Today, AI tools help programmers write code faster, fix mistakes, and build software more easily."*

* **Traducción al español:**
  > "Ahora, permítanme compartir tres datos fascinantes sobre la tecnología:  
  >  
  > Primero: Ada Lovelace fue la primera programadora de computadoras de la historia. En el siglo XIX, escribió el primer algoritmo para una calculadora mecánica temprana, mucho antes de que se inventaran las computadoras electrónicas.  
  >  
  > Segundo: A escala global, millones de desarrolladores programan en JavaScript y Python todos los días. JavaScript potencia sitios web interactivos en nuestros navegadores, mientras que Python es el lenguaje número uno para Ciencia de Datos e Inteligencia Artificial.  
  >  
  > Y tercero: En esta era moderna, las aplicaciones web y la IA están transformando el mundo. Hoy en día, las herramientas de IA ayudan a los programadores a escribir código más rápido, corregir errores y construir software más fácilmente."

* **Desglose detallado y pronunciación punto por punto:**

  1. **Dato 1 - Ada Lovelace:**
     * **Frase clave:** *"She wrote the first algorithm for an early mechanical machine."*
     * **Pronunciación:**
       * **Nineteenth century:** `[náin-tiinz sén-chu-ri]` *(siglo XIX)*
       * **Algorithm:** `[ál-go-ri-zom]` *(el sonido 'th' suave como zeta española)*
       * **Mechanical:** `[me-ká-ni-kal]`
       * **Invented:** `[in-vén-tid]`

  2. **Dato 2 - JavaScript & Python:**
     * **Frase clave:** *"JavaScript powers interactive websites, while Python powers Artificial Intelligence."*
     * **Pronunciación:**
     * **Global scale:** `[glóu-bal skéil]`
     * **Powers:** `[páu-ers]` *(hace funcionar / da poder)*
     * **Browser:** `[bráu-ser]` *(navegador web)*
     * **While:** `[wáil]` *(mientras que...)*

  3. **Dato 3 - Era Moderna & IA:**
     * **Frase clave:** *"AI tools help programmers write code faster and fix mistakes."*
     * **Pronunciación:**
     * **Modern era:** `[mó-dern í-ra]`
     * **Transforming:** `[trans-fór-ming]`
     * **Faster:** `[fás-ter]` *(más rápido)*
     * **Mistakes:** `[mis-téiks]` *(errores / fallos)*
     * **Easily:** `[í-si-li]` *(fácilmente)*

* **💡 Tip para esta diapositiva:**  
  Señala con tu mano o con la vista cada una de las 3 tarjetas en pantalla a medida que dices *"First..."*, *"Second..."* y *"Third..."*. Esto le demuestra al evaluador que estás conectando tu discurso con las diapositivas.

## 💡 Consejos Clave para tu Presentación Oral

1. **Ritmo pausado:** No hables rápido. En nivel A1, los evaluadores valoran mucho más la claridad y la buena pronunciación que la velocidad.
2. **Postura y mirada:** Mira a tu audiencia o a la cámara. Usa las teclas `←` y `→` o la barra espaciadora para cambiar de diapositiva con naturalidad.
3. **Respiración:** Toma aire al cambiar de diapositiva.
4. **Respuestas a preguntas típicas del profesor/evaluador:**
   * *Where do you work?* $\rightarrow$ *"I work remotely from home."*
   * *What is your favorite programming language?* $\rightarrow$ *"My favorite language is JavaScript (o Python) because it is very useful."*
   * *What game do you play?* $\rightarrow$ *"I play Valorant with my friends."*
